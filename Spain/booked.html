Read this first — the eclipse

The total eclipse is Wednesday, August 12. The hotel booked for that night is CC Opera Suites in Madrid (August 11–14, paid, non-refundable).

Madrid is not in the path of totality. It gets a 99.96% partial eclipse — the sun never fully disappears, there is no corona, no darkness, no horizon-to-horizon sunset. It is a fundamentally different event from a total eclipse.

One more thing about this eclipse: totality happens with the sun only a few degrees above the horizon, so wherever you end up, you need an unobstructed view to the west — no ridgeline, no buildings. That matters more than the exact town.
